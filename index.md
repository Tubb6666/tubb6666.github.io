## 📚 What Is WebsiteStars?

WebsiteStars is a simple, friendly tool that helps you **save websites you like** and **find them again later**. Think of it as a personal library for everything you read online. When you come across a useful GitHub page, an interesting article, or a helpful document, WebsiteStars saves a copy for you. No complicated setup. No programming knowledge required. Just save, search, and go.

## 🎯 How to Use WebsiteStars

### Saving a Website

1. While browsing, click the **WebsiteStars icon** in your browser toolbar.
2. A small window pops up showing the page title and address.
3. Add optional tags (like "coding," "recipes," or "work").
4. Click **Save**. Done!

The page is now stored in your personal library.

### Searching Your Library

1. Click the WebsiteStars icon again.
2. Type any keyword in the search box.
3. Matching results appear instantly. Click one to reopen the page.

### Asking AI Questions (Optional)

If you enable the AI feature, you can type questions like "What did I save about React hooks?" and get answers based on your saved content. This feature works best when you have multiple related saves.

## 🛠️ Troubleshooting

**WebsiteStars won't install?**
- Make sure you're using Chrome 120 or newer. Update Chrome from the settings menu.
- Try downloading the file again—sometimes downloads get interrupted.

**The icon doesn't appear after installation?**
- Restart your browser completely (close all windows and reopen).
- Check your extensions list in Chrome settings to ensure WebsiteStars is enabled.

**Search returns no results?**
- Make sure you've saved items first. The search only works within your saved library.
- Try using different keywords or fewer words.

**AI feature not working?**
- Check your internet connection—AI requires an active connection.
- Ensure you've enabled the feature in WebsiteStars settings.
